# Demo data

`altais-demo-sk.json` and `altais-demo-en.json` are the demo packages of
[ADR-0005](../../docs/adr/0005-demo-data.md). They are generated by
`generate.py` (run it from the repository root; it needs `pip install blake3`)
and bundled with the desktop app.

**Licence: CC0 1.0.** All texts and the picture were written or drawn for
ALTAIS; there is no third-party material and no personal data in them.

Format (`"format": "altais-demo", "version": 1`): notebooks, notes as ADM
blocks with an age in days (dates are set relative to the day the demo is
loaded), and attachments as base64 keyed by their BLAKE3 content address, so
every attachment is checked when it is loaded.
